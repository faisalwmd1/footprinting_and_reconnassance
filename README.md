# footprinting_and_reconnassance

Footprinting and reconnaissance form the initial, intelligence-gathering phase of a security assessment or cyberattack. The goal is to collect as much information as possible about a target organization, network, or system to map out its attack surface without making unauthorized changes.

# wafw00f
# wafw00f command
During a penetration test or security audit, running heavy exploit tools or vulnerability scanners can be completely blocked if a WAF is active. Security researchers use wafw00f early in the information-gathering phase for several key reasons:Detects the Presence of a WAF: It quickly confirms whether a web application is sitting behind a firewall layer.Fingerprints the Vendor: It identifies the specific brand or product being used (e.g., Cloudflare, AWS WAF, Akamai, or Imperva).Prevents Waste of Time: Knowing the firewall type allows testers to avoid using standard attack payloads that will instantly trigger security alerts, allowing them to switch to custom bypass strategies instead.Discovers Known Vulnerabilities: Identifying the exact version or vendor of a WAF can reveal if the firewall software itself has any known vulnerabilities or configuration flaws.

# dnsrecon -d
# dnsrecon -d command

By pointing dnsrecon at a target domain using -d, the tool queries DNS servers to map out the organization's digital infrastructure by collecting:A and AAAA Records: Maps hostnames to their respective IPv4 and IPv6 addresses.NS (Name Server) Records: Identifies the authoritative servers managing the domain's DNS.MX (Mail Exchanger) Records: Discovers the mail servers handling the organization's email traffic.SOA (Start of Authority) Records: Gathers administrative details about the zone.TXT Records: Often reveals hidden configuration metadata, such as SPF or DKIM strings used for email security.
